# WL Tracker 365 — Elenco editável

Mini app para controlar sua Weekend League como um FUT Stats Tracker simples.

## Como usar
1. Abra o arquivo `index.html` no navegador.
2. Vá em **Registrar** para preencher os 15 jogos.
3. Use os botões `+` e `-` para gols e assistências de cada jogador.
4. Marque o MVP da partida.
5. Veja os rankings em **Home**, **Ranking**, **Elenco** e **Resumo**.

## Novidades desta versão
- Aba **Gerenciar** para adicionar, remover e editar jogadores.
- Botão **Salvar e iniciar nova WL** para guardar a WL no histórico.
- Aba **Histórico** com as WLs salvas.
- Você não precisa mexer no código para trocar o time.

## Observação importante
Os dados ficam salvos no navegador/celular usando `localStorage`.
Se você limpar os dados do navegador, pode perder o histórico.
