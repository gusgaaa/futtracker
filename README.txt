# Fut Tracker

Versão com:
- nome Fut Tracker;
- visual inspirado em FC 26;
- elenco editável;
- histórico de WL;
- exportação e importação de backup.

## Como usar
1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador.
3. Use a aba Registrar para lançar as partidas.
4. Use a aba Gerenciar para editar o elenco.
5. Use a aba Backup para exportar/importar seus dados.

## Observação
Os dados ficam salvos no navegador via localStorage.
O backup em .json serve para restaurar tudo depois.
